TVDB Community Fix

A patched fork of the official Jellyfin TVDB plugin.

What this fixes

The upstream TVDB v4 API returns an empty episode array for the altdvd and alttwo season types (see thetvdb/v4-api#340, open since late 2023). This plugin falls back to per-season fetches when the primary endpoint comes back empty.

Install

  1. Open Jellyfin: Dashboard, Plugins, Repositories, plus button.
  2. Name: TVDB Community Fix
  3. URL: https://superuser404notfound.github.io/jellyfin-plugin-tvdb/manifest.json
  4. Save, then go to the Catalog tab and install TVDB Community Fix.
  5. Uninstall the official TheTVDB plugin and restart Jellyfin.
